# Recommendation purpose and measured progress

The purpose sentence describes the existing plan; it does not select a new workout or alter ladder, load, rest, or zone rules. Ladder advancement means progression, repeat/incomplete means consistency, and recalibration/down-step means rebuilding consistency. Without a ladder, cold-start/boundary/coverage probes are labeled evidence collection; other recommendations are described as capacity building without asserting an optimal adaptation target.

Analysis compares each grip and hand separately using valid measured session openers. The latest measured opener defines the comparison neighborhood: durations within a maximum/minimum ratio of 1.10 for force progress, or measured force within that ratio for hold-duration progress. Available setup identifiers must match. Historical best is the highest recorded outcome within this comparison neighborhood, not a fitted potential or global best across unlike efforts.

Recent performance is the median of the latest three comparable sessions versus the preceding three within 90 days, with at least one observation in the last 30 days. Fewer than six sessions is insufficient evidence. More than 5% upward change is labeled improving; more than 5% downward change is lower recently; smaller changes are broadly unchanged. These engineering thresholds provide descriptive summaries, not statistical significance or causal attribution. No interpolation or fatigue-normalized predictions are used.

Repeated effort compares second-rep duration divided by opening duration. It additionally requires valid consecutive recovery evidence, comparable measured force and opener duration, and rest within 10% (at least one second tolerance). The shared recovery-evidence reader requires actual rest for current records; eligible legacy records before September 11, 2026 can use planned rest as a historical estimate. The view discloses that limitation. Best-ever values appear separately from recent medians. Old measured averages remain available with a measurement-uncertainty note.

Limits: unknown historical setup, climbing exposure, and warm-up conditions cannot be verified; similar is not identical force/duration. These comparisons do not isolate adaptation from fatigue or other circumstances. The view is a compact way to inspect existing results, not a new benchmark protocol.

The measured-progress card is visible immediately above the performance trend
cards instead of inside the curve-improvement disclosure. Insufficient evidence
is shown once for the selection, alongside the six-session and recency rules.
When every comparison is insufficient and the largest matching group has fewer
than six sessions, that count is shown. This count describes existing comparable
records; it is not a workout recommendation. A moving fitted curve does not
resolve an insufficient measured comparison. Available results also disclose
that fatigue and measurement conditions can differ and that unlogged climbing
is not numerically corrected.

Validation: synthetic increases, declines, unchanged results, insufficient/stale data, interrupted efforts, nominal loads, session independence, changed setup/rest, future exclusion, legacy uncertainty, purpose precedence, and UI empty state.

## Session performance context

Setup exposes an expandable recent-session note based on the same measured opener comparisons. It distinguishes steady/improving, lower, mixed, and insufficient opening evidence from lower later-rep performance. Neither establishes readiness today. The existing cookedness adjustment remains unchanged. Calendar-recency scoring no longer consumes fitted between-rep recovery constants; personalized within-set forecasts retain those constants. This is a separation of evidence and a removal of the seconds-to-days assumption, not a new automatic readiness gate.
