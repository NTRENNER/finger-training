# Actual progress and calibrated performance

Analysis separates two questions that should not be conflated.

## Measured progress inside Curve Improvement

Each Curve Improvement tile finds the newest valid measured opening hold with an older compatible repeat in each of
the five trained duration domains: Power, Power-Strength, Strength,
Strength-Endurance, and Endurance. It displays the observed force and observed
duration beside the earliest compatible repeat beneath the modeled percentage or weight comparison.
Instantaneous Peak Force is the sixth tile and is labeled separately from the
modeled five-second Max value.

Workouts are grouped by their prescribed domain, so an Endurance prescription
remains in Endurance even when its achieved opening hold lands short or long.
Pooled values average the available opening hands within each workout. Nominal
loads, interrupted efforts, and fitted values are excluded. A duration is considered matched within 10% (or 2 seconds, whichever is larger); force is considered matched within 5% (or 0.25 kg, whichever is larger). If neither dimension matches, the tile falls back to the calibrated baseline and current curves at that domain's fixed reference duration when both are supported. This fallback is labeled as estimated and never presented as a measured repeat. If no supported calibrated comparison exists either, the tile reports that no like-for-like repeat exists rather than implying progress. Each evidence strip
opens the same measured-only workout history used to calculate its comparison. The Peak Force strip instead opens the complete Peak Force trend
and compares the first observed peak with the current all-time best.

These comparisons are descriptive. They do not hold force or duration constant,
adjust for fatigue, or claim causality. A heavier but shorter latest hold is
shown as exactly that rather than being collapsed into one score.

## Recent Performance vs Expected

This chart compares each valid opening hold with the calibrated personal curve
saved before that workout. Older records reconstruct the expectation from
strictly earlier history. The workout being scored cannot alter its own expected
value. Logged climbing load remains context only and does not refit the curve.

Validation covers measured-only filtering, interrupted and nominal records,
first/latest ordering, pooled and per-hand views, all five trained domains,
instantaneous peaks, unit conversion, empty states, and the workout-history
drill-down.
