# Optional sets and the rep ladder

The first set remains the prescribed workout. Its existing progression is unchanged: earn rep five, then rep six, then increase load and return to four reps. Optional sets do not change those decisions or contribute fresh capacity evidence.

An automatic suggestion for a second set requires all of the following:

- Every prescribed rep is recorded for every selected hand, with valid capacity evidence and adequate within-set performance.
- The first-set ladder decision is to repeat. An earned rep increase, load increase, recalibration, or incomplete set suppresses the suggestion.
- The latest three comparable sessions, including the current session, fall within 30 days. Invalid or unsuccessful attempts are not skipped to construct a plateau.
- The sessions have the same rep count, setup, target duration, and planned rest. Opening force and each rep’s hold time vary by no more than 3%. More reps or longer holds at a fixed load count as progress.

Rare exposure alone never justifies adding volume. Later optional sets retain their fresh-opener retention and within-set performance checks, and must also be complete before suggesting another. Five sets remains the limit. The manual add-set action remains optional and available without an automatic suggestion.

A partial workout is labeled “Session Ended Early”; its recorded activity is preserved. Completion is distinct from evidence validity, so interrupted reps retain their individual labels even in a fully recorded set.
