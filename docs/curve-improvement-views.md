# Curve Improvement views

Curve Improvement remains the main finger progress card. Percentage is the default, with the existing six zones and overall percentage retained.

- **Weight** evaluates baseline and selected-date curves at each existing zone reference duration. Each tile shows the load difference, baseline → current load, and fixed duration. Loads are in the user's kg/lbs unit; there is no misleading total load summed across domains. Clicking the modeled portion of a Weight tile selects a dated weight-over-time chart at that domain’s fixed duration. Its headline agrees with the tile, its baseline respects later-supported domains, and a separate button opens session history. Exact-duration measured holds can appear as green dots. Phone layouts use two columns and wider layouts use three.
- **Time** retains six clickable domain boxes, each showing estimated time gained and its fixed comparison weight. Selecting a box updates the single detailed chart and baseline weight label below it. The comparison headline states the change in plain language: “At X kg/lbs, your estimated hold time went from A seconds to B seconds.” It uses the selected historical date, labels the estimate explicitly, and handles gains, unchanged performance, and declines without assuming improvement. Unsupported comparisons show a dash and remain selectable. This view evaluates both curves at one fixed physical load and plots the estimated duration over session dates. The initial load comes from a measured baseline-date pull near the domain's duration (within half to twice its reference duration), when available and supported. Otherwise it uses the baseline curve's load at that duration. New workouts do not move this reference. Comparison weights are selected automatically from the baseline and cannot be edited.
- Percentage follows the page's absolute/bodyweight choice. Weight and Hold time use absolute physical load so changing bodyweight cannot change the benchmark. Unit conversion changes presentation, not the stored comparison weight.

The new view does not change prescriptions, zone definitions, recording, or failure rules. Overshoots remain eligible evidence under the existing curve-fit rules. Recorded dots use valid measured opening pulls at the exact comparison load (within numerical tolerance of 0.000001 kg); prescribed-only values and interrupted efforts cannot become measured dots. Each date's dot is its longest matching recorded hold; the expanded list retains all matching observations and hand labels. Curve estimates still use other eligible loads and durations through the existing fits.

Hold-time inversion is bounded from the curve's five-second reference minimum through the longest supporting hold for that date. Loads outside that supported range produce an unavailable estimate, not zero, a capped time, or an extrapolated gain. Recorded dots remain available even when an estimate is unavailable. Gaps stay gaps. Later-supported domains use their own baseline and cannot borrow a baseline after the selected comparison date.

Peak force remains a standalone history card, and its measured summary also appears in the Max tile. Every Curve Improvement tile now pairs its modeled comparison with a compact measured strip. The five trained duration domains show the first and latest valid measured opening hold; clicking that strip opens measured-only workout history. Max explicitly shows instantaneous first-to-best Peak Force and opens the full Peak Force trend. The standalone Actual Progress by Domain card was removed because these paired signals are clearer when read together.

Validation covers analytical inverse solutions, all six reference durations, unchanged and declining curves, unsupported loads, later baselines, interruptions, hand/date scoping, kg/lbs conversion, bodyweight changes, and fixed-weight stability. The card was also inspected in a browser with synthetic data at desktop and phone widths. This is not a physical sensor validation or a comparison against the user's live database.

## Analysis layout

Peak Force appears first, followed by Recorded Pulls and Current Curve, Recent Performance vs Expected, and Curve Improvement. Recovery Status and Estimated Capacity Over Time are removed from Analysis. Recovery still informs workout recommendations and weekly coaching without occupying a standalone chart.
